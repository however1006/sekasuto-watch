# セカスト新着ウォッチャー

セカスト オンラインストアの新着を10分おきにチェックし、上限価格以下の商品が出たら Discord に通知します。GitHub Actions で動かすので、PCを閉じていても動き続けます。新着を見つけた時刻も記録し、毎週月曜に「何時台に新着が多いか」の集計を Discord に送ります。

## できること

- ブランド（キーワード）ごとに、新着順の検索結果1ページ目（60件）をチェック
- 前回までになかった商品のうち、上限価格以下・除外ワードなしのものだけ通知
- 通知には画像、価格、状態、サイズ、上限までの差額、想定利益（売値を設定した場合）を表示
- 新着の記録（CSV）と時間帯別・曜日別の集計を、毎週月曜 9時ごろ Discord に送信

---

## セットアップ（GitHub Actions で動かす）

所要時間は20〜30分です。

### 1. Discord の通知先を作る
1. Discord（無料）に登録し、左の「＋」→「オリジナルの作成」で自分だけのサーバーを作る
2. 通知用チャンネルの歯車アイコン →「連携サービス」→「ウェブフック」→「新しいウェブフック」
3. 「ウェブフックURLをコピー」してメモ帳に貼っておく
4. スマホにも Discord アプリを入れておくと、プッシュ通知が届きます

※ Webhook URL を知っている人は誰でもそのチャンネルに投稿できるので、他人に見せないでください。

### 2. 設定（監視するブランドと価格）を作る
`config.example.json` をメモ帳などで開き、`watches` の中身を自分の得意ブランドと価格に書き換えます。`discord_webhook_url` の行は空のままで構いません（URLは手順5で別に登録します）。

| 項目 | 意味 |
|---|---|
| `quiet_hours` | チェックしない時間帯（日本時間）。例は1〜6時 |
| `shipping_cost` | メルカリで売るときの送料の目安 |
| `global_exclude` | 全ブランド共通の除外ワード |

`watches` の各項目：

| 項目 | 意味 |
|---|---|
| `label` | 通知に表示する名前 |
| `keyword` | セカストで検索する言葉 |
| `brand_contains` | ブランド欄にこの文字が入っている商品だけ対象（別ブランドの混入防止） |
| `max_price` | 仕入れ上限価格。これ以下だけ通知 |
| `expected_sell_price` | メルカリでの想定売値（任意）。入れると想定利益を表示 |
| `exclude` | このブランドだけの除外ワード（任意） |
| `include_any` | どれかを含むものだけ通知（任意。例：アウターだけ狙う） |

サンプルの価格は仮の数字です。編集し終わったら、ファイルの中身を全部コピーしておきます（手順5で使います）。

### 3. GitHub のアカウントとリポジトリを作る
1. https://github.com で無料アカウントを作る
2. 右上の「＋」→「New repository」
3. Repository name に `sekasuto-watch` などと入力
4. **Public** を選んで「Create repository」

**なぜ Public（公開）なのか**：GitHub Actions は公開リポジトリなら無料で使い放題ですが、非公開リポジトリは無料枠が月2,000分です。10分おきに動かすと月4,000回以上になり、非公開だと枠を超えてしまいます。

**公開しても見えないもの**：ブランドと価格の設定、Webhook URL は「シークレット」として暗号化して保存するので、他人には見えません。見つけた商品の記録もリポジトリには保存せず、実行ログにもブランド名や商品名は出しません。公開されるのはプログラムのコードだけです。

### 4. ファイルをアップロードする
作ったリポジトリの画面で「uploading an existing file」をクリックし、このフォルダの中身をまとめてドラッグ＆ドロップして「Commit changes」。

- `sekasuto_watch.py`
- `README.md`
- `config.example.json`
- `.github` フォルダ（中に `workflows/watch.yml` と `workflows/report.yml`）

**`.github` フォルダが見えないとき**：名前が「.」で始まるフォルダは隠しフォルダ扱いです。Mac は Finder で `Cmd + Shift + .`、Windows はエクスプローラーの「表示」→「隠しファイル」で表示できます。

**config.json は絶対にアップロードしないでください**（設定は次の手順でシークレットに入れます）。

### 5. シークレットを登録する
リポジトリの「Settings」→ 左メニュー「Secrets and variables」→「Actions」→「New repository secret」で、次の2つを登録します。

| Name | Secret に入れるもの |
|---|---|
| `DISCORD_WEBHOOK_URL` | 手順1でコピーした Webhook URL |
| `CONFIG_JSON` | 手順2で編集した設定ファイルの中身すべて |

### 6. 動作確認
1. リポジトリの「Actions」タブを開く（有効化を求められたら「I understand…」で有効化）
2. 左の「新着の集計をDiscordに送る」→「Run workflow」→ 緑の「Run workflow」
   → Discord に「まだ新着の記録がありません」と届けば、通知の設定はOKです
3. 左の「セカスト新着チェック」→「Run workflow」で1回手動実行
   → 緑のチェックがつけば成功。実行ログに「初回のため ○ 件を記憶」と出ます

あとは10分おきに自動で動き、2回目以降の新着から通知が届きます。

## よくある質問

**設定（ブランドや価格）を変えたい**
「Settings」→「Secrets and variables」→「Actions」→ `CONFIG_JSON` の鉛筆アイコンから、設定ファイルの中身を丸ごと貼り直します。

**止めたい・再開したい**
「Actions」→「セカスト新着チェック」→ 右上の「…」→「Disable workflow」で停止、「Enable workflow」で再開。

**実行ログに「取得失敗」が続く**
GitHub のサーバーは海外にあるため、セカスト側が海外からのアクセスを制限している場合は取得できません。その場合はPCで動かす方法に切り替えてください（下記）。

**10分ぴったりに動かない**
GitHub が混雑していると、実行が数分〜十数分遅れたり、まれに1回飛ばされたりします。無料の仕組みなので、多少の遅れは前提にしてください。

**しばらくしたら動かなくなった**
公開リポジトリでは、60日間リポジトリに変更がないと定期実行が自動で止まります。GitHub からメールで予告が来るので、届いたら「Actions」で「Enable workflow」を押すか、README を少し編集して保存してください。

## PCで動かす場合（参考）

Python を入れたうえで、`config.example.json` をコピーして `config.json` を作り、`discord_webhook_url` に Webhook URL を入れます。このフォルダでターミナルを開いて次を実行すると、10分おきにチェックし続けます（Mac は `python3`）。

```
python sekasuto_watch.py          # 監視を開始（Ctrl + C で停止）
python sekasuto_watch.py --test   # Discord へのテスト通知
python sekasuto_watch.py --report # 新着の時間帯を集計
```

## 注意

- 個人の仕入れ判断のためのツールです。集めたデータを公開・販売しないでください。
- サイトに負荷をかけないよう、間隔は10分以上、ブランド数は10〜15個程度にとどめてください。
- 自動購入の機能はありません。通知から商品ページを開き、自分で判断して購入してください。
- セカストのサイトの作りが変わると、商品を読み取れなくなることがあります。そのときは実行ログに「商品が読み取れませんでした」と出ます。
